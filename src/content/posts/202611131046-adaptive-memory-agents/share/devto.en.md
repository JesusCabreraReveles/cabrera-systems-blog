> A Google plugin with adaptive memory, where other agents validate the work without any memory, is helping me approve tasks with fewer tokens and less rework.

I've started testing a plugin Google released called [Elephant Golden Fish]. I'm using it to build a development environment I call [OrqestrAI].

## Adaptive memory per project

What interested me most is that the plugin gives you adaptive memory about your project.

![Photo of two stamps pressed onto cream paper: a pink elephant and a fish outlined in dark blue, next to a clear acrylic block.](https://raw.githubusercontent.com/JesusCabreraReveles/cabrera-systems-blog/master/src/content/posts/202611131046-adaptive-memory-agents/img-1.webp)

## Memoryless agents as validators

Some agents work from scratch, without that memory. Their job is to check that what was defined at the start actually got done. I think it's a really good idea, and I like it a lot.

![Blue graphic titled "Google EGM: Goldfish Attack Plans!" with a white icon that "remembers everything" and an arrow pointing to an orange fish icon that "remembers nothing"; label "1 real bug".](https://raw.githubusercontent.com/JesusCabreraReveles/cabrera-systems-blog/master/src/content/posts/202611131046-adaptive-memory-agents/img-2.webp)

## OrqestrAI: simulated Scrum

[OrqestrAI] simulates a Scrum process to run projects. Several agents have different roles, such as Product Owner, Architect, or Scrum Master. The idea is to see how they handle tasks.

## Validation between agents

The plugin is helping a lot with getting agents to validate each other and approve finished tasks. It has noticeably reduced token consumption and rework.
